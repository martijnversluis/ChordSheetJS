# ChordSheet Symbols font

`ChordSheet Symbols` is the tiny PDF chord-symbol face generated by
`build_symbol_fonts.ts`. It is a modified subset of Noto Sans Symbols and remains
under the SIL Open Font License 1.1.

## Build

```sh
yarn fonts:build
yarn fonts:check
```

`fonts:check` generates the expected module in memory and compares it byte-for-byte
with the committed file. It is part of the normal unibuild lint checks.

Both commands run through the repository's existing `tsx` toolchain. The generator
uses the locked `fonteditor-core` package to read and write TrueType fonts.
Generated temporary TTFs are written to `tmp/chordsheet-symbol-fonts`; the
committed runtime artifact is
`src/formatter/pdf_formatter/fonts/ChordSheetSymbolsFonts.base64.ts`.

## Glyphs

- U+266D `♭` musical flat sign
- U+266E `♮` musical natural sign
- U+266F `♯` musical sharp sign
- U+0394 `Δ` Greek capital delta (major chord)
- U+2206 `∆` increment (major chord alias)
- U+25B3 `△` white up-pointing triangle (major chord alias)
- U+00B0 `°` degree sign (diminished chord)
- U+00F8 `ø` Latin small letter o with stroke (half-diminished chord)
- U+2300 `⌀` diameter sign (optional half-diminished alias)

The three major-triangle code points use visually identical but distinct glyphs.
Distinct glyph IDs are required so jsPDF's ToUnicode map preserves the original
character during PDF text extraction.

## Design adjustments

`FLAT_X_SCALE` and `FLAT_Y_SCALE` in `build_symbol_fonts.ts` control the flat
outline and metrics. The current design is 15% larger in both dimensions than
the previous widened flat, for total source scales of 1.38x and 1.3225y.
`SHARP_BASELINE` raises each sharp outline so its lower edge rests exactly on the
chord-letter baseline without changing its shape or advance width.
The major triangle is constructed by `triangleGlyph`; Regular and Bold use
different inner contours to produce different stroke weights.

Every outline change must update horizontal metrics in the generated TTF. Verify
changes with the real-jsPDF tests and a PDF specimen because measurement and final
rendering intentionally share these metrics.
